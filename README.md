
# Proyecto Colaborativo – GitHub Practice  

## 📌 Descripción  
Este proyecto fue creado como práctica para aprender y aplicar conceptos de **control de versiones con Git y GitHub**, trabajando de forma colaborativa en un mismo repositorio.  

Durante la actividad se trabajó con:  
- Creación de repositorio  
- Manejo de ramas  
- Commits claros  
- Issues  
- Forks  
- Pull Requests (PRs)

## 🔄 Flujo de trabajo aplicado  
1. Nathaly creó el repositorio inicial en GitHub.  
2. Cada integrante realizó un **fork** del repositorio.  
3. Los forks fueron **clonados** en sus computadoras para hacer cambios.  
4. Cada compañera creó una **rama** para trabajar de forma independiente.  
5. Se hicieron **commits** con mensajes que describen los cambios.  
6. Se abrieron **Pull Requests (PRs)** desde las ramas de los forks hacia `main` del repositorio original.  
7. Nathaly revisó y aprobó los PRs, haciendo **merge**.  
8. También se utilizaron **issues** como parte de la organización.
